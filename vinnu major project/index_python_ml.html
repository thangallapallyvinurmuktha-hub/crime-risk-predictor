Technical Documentation

HOW IT
WORKS

A complete overview of the machine learning pipeline, data processing, and model architecture behind this platform.

DATASET

1,200 records spanning 20 years (2005–2024) across 60 districts in 12 Indian states. Zero missing values — clean, well-structured CSV data.

  • 0112 states, 60 districts covered
  • 026 crime categories: Murder, Rape, Kidnapping, Theft, Cyber Crime, Total
  • 03Population data for per-capita normalisation
  • 04No null values — 100% data quality

ML MODELS

Two models are trained using scikit-learn on the full dataset with label encoding for categorical features.

  • M1Random Forest Classifier — predicts dominant crime type (Theft, Cyber Crime, Kidnapping)
  • M2Gradient Boosting Regressor — predicts risk score 0–10 based on per-100k-population normalisation
  • FEFeatures: Year, State (encoded), District (encoded), Population

TECH STACK

Python for data science, self-contained HTML/CSS/JS for the frontend — deployable on any platform.

  • PYPython 3 — data processing & model training
  • PDPandas — data loading, cleaning, feature engineering
  • SKscikit-learn — Random Forest, Gradient Boosting
  • JSChart.js — all interactive visualisations

RISK FORMULA

The risk score is computed using a two-step normalisation and prediction pipeline.

  • 1Raw score = Total_Crime / Population × 100,000
  • 2Min-max normalise across all districts → 0 to 10 scale
  • 3GBR model learns to predict this score for future years
  • 42025 is predicted by extrapolating from the 2024 trend
